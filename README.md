# PopClip 扩展

两个 [PopClip](https://pilotmoon.com/popclip/) 扩展：「中文排版」用来一键清理中文文本的排版——尤其适合清理 AI（ChatGPT / Claude 等）输出、PDF 复制粘贴的中文；「MotrixNext 下载」把选中的下载链接直接发给 [MotrixNext](https://github.com/AnInsomniacy/motrix-next) 下载器：

| 扩展 | 按钮 | 做什么 |
|---|---|---|
| **中文排版** | 隔 | 间隔标准化：标点中文化 + 删不合理空格 + 中英文间加空格（一站式，推荐） |
| **中文排版** | 标 | 中文标点规范化：只做标点中文化，不动任何空格 |
| **MotrixNext 下载** | ⏬ | 选中链接一键发给 MotrixNext（弹「新建任务」面板确认） |

「隔」「标」是「中文排版」一个扩展里的两个按钮，共用同一套标点转换引擎，可在 PopClip 设置 → 扩展 → 中文排版的选项里分别开关（默认都显示）。两个按钮都是**单向**转换（英 → 中），且**只在判定为中文语境时才动手**，不会破坏数字、网址、代码、时间、路径等内容；对已规范的文本重复运行不再改动（幂等）。

## 「隔」间隔标准化（推荐）

对选中文本按序执行：

0. **保护区**：``` 围栏代码块、`` `行内代码` ``、`https://`/`www.` 开头的网址**整体跳过**，一个字符都不动；
1. **全角字母数字折回半角**：`ＡＢＣ１２３` → `ABC123`（全角标点不在此列，按语境走第 3 步）；
2. **去掉不合理的空格**：汉字之间的空格（PDF 换行残留）、全角标点两侧的空格删除，连续空白收拢为一个半角空格；
3. **标点中文化**：与「中文标点规范化」同一套成对判定逻辑，另加 `--` → `——`、日式半角标点 `｡ ､ ｢ ｣ ･` 的映射；已在 `“ ”` 或 `「 」` 里的直双引号按国标降级为 `‘ ’`（双内用单）；
4. **盘古之白**：汉字与英文/数字交界处补一个半角空格，货币符号（`$100`、`¥199`）、单位与串尾符号（`50%`、`25℃`、`m²`、`C++`）随西文串一起处理。

步骤 2、3 交替迭代至不再变化，因此一次点击即得终态，重复运行也不会再改动（幂等）。

```
输入：卢卡奇在1923年出版了《历史与阶级意识》,书中说「第二自然」(zweite Natur)统治着人 。相关讨论增长了300%左右...详见第2章｡

输出：卢卡奇在 1923 年出版了《历史与阶级意识》，书中说“第二自然”（zweite Natur）统治着人。相关讨论增长了 300% 左右……详见第 2 章。
```

空格处理的边界（有意的设计）：

- **行首缩进**（含全角空格缩进）、**行尾空格**（Markdown 硬换行）、**制表符**（TSV）、单个**不换行空格**（nbsp）原样保留；
- Markdown **列表标记**（`- ` `1. ` `> `）后的对齐空白、**表格** `|` 两侧的空格保留；
- 汉字之间的空格一律删除——含 `第一章 绪论` 这类标题空格，如需保留请只选正文；
- 英文行文里的空格只收拢不删除，纯英文文本不会被改动；
- `—` `…` `·` 中英通用，只有两端都贴着中文才删空格（`Vue — 渐进式框架` 原样保留）；
- 盘古之白只认汉字，全角标点旁（`，` `：` 等自带留白）不加空格；空格永远补在 `**` `` ` `` 等 Markdown 标记的**外侧**，不破坏加粗/行内代码；词内下划线（`订单_id`）不拆。

## 「标」中文标点规范化

只做标点转换、完全不碰空格的保守版本——不删不加任何空格，也不折全角字母数字（`ＡＢＣ１２３` 保持原样）。标点转换与「隔」共用同一套引擎：直引号 `" '` → 中文弯引号（整对配对判定、双内用单）、繁体角引号 `「」『』` → 简体弯引号、半角句读 `, ; : ? ! . ( )` → 全角、`...` → `……`、`--` → `——`、日式半角 `｡ ､ ｢ ｣ ･` 直接映射；代码块、行内代码与网址同样整体保护。适合不想让工具动空格的场合。

```
输入：他的命题是:商品交换在古老社会里就存在了,但只是偶然地出现(部落间的物物交换)。卢卡奇说「第二自然」(zweite Natur)其实是'人造世界'...对吗?

输出：他的命题是：商品交换在古老社会里就存在了，但只是偶然地出现（部落间的物物交换）。卢卡奇说“第二自然”（zweite Natur）其实是‘人造世界’……对吗？
```

## 共同的转换规则

| 类别 | 半角 / 繁体 | → 全角（简体） | 说明 |
|---|---|---|---|
| 引号 | `"` `'` | `“ ”` `‘ ’` | 仅中文语境，自动成对；保护英文撇号 `don't` 与英寸 `6"` |
| 角引号 | `「」` `『』` | `“ ”` `‘ ’` | 繁体引号 → 简体引号 |
| 逗号 | `,` | `，` | |
| 分号 | `;` | `；` | |
| 冒号 | `:` | `：` | 后跟空格的“标签: 值”保持半角 |
| 问号 / 叹号 | `?` `!` | `？` `！` | |
| 句号 | `.` | `。` | 仅句末；小数 / 缩写 / 域名不动 |
| 括号 | `( )` | `（ ）` | 成对转换；函数调用与 Markdown 链接保持半角 |
| 省略号 | `...` | `……` | 仅贴着汉字时 |
| 破折号 | `--` | `——` | 恰两个连字符且贴汉字，`--help`、`---` 分隔线不动 |
| 日式半角 | `｡ ､ ｢ ｣ ･` | `。 、 “ ” ·` | 直接映射 |

## 不会误伤

判断逻辑是“标点紧贴汉字才转”，因此技术内容天然安全：

| 输入 | 输出（不变的部分） | 原因 |
|---|---|---|
| `1,000,000` / `3.14` / `v2.0.1` | 同上 | 数字、版本号 |
| `12:30` / `2:1` | 同上 | 时间、比例 |
| `http://a.com/x?y=1` / `http://例子.测试` | 同上 | 网址（含未编码中文的也整体保护） |
| `user@mail.com` | 同上 | 邮箱 |
| `C:/Users/me` | 同上 | 路径 |
| `func(x)` / `print("你好")` / `[链接](http://x)` | 同上 | 调用型括号内部视为代码 |
| `{"姓名":"张三"}` / `<div class="标题">` | 同上 | JSON 花括号内部、`="…"` 属性赋值 |
| ```` ```代码块``` ```` / `` `行内代码` `` | 同上 | Markdown 代码保护区 |
| `don't` / `6'5"` / `--help` | 同上 | 英文撇号、英尺英寸、命令行参数 |
| `So…?` / `word — word` | 同上 | 英文里的省略号、破折号不构成中文语境 |
| `哈哈 :)` | 同上 | 颜文字（也不会被别的括号“偷配对”） |
| `端口: 8080` | 同上 | 西式“标签: 值” |

Markdown 行内标记 `**粗体**`、`_斜体_`、`~删除~` 会被「看穿」（不妨碍对汉字的判断，也不妨碍加/删空格），并原样保留。

## MotrixNext 下载

选中含链接的文本，点 ⏬ 把链接交给 [MotrixNext](https://github.com/AnInsomniacy/motrix-next)——它会弹出「新建任务」面板供确认，**不会静默开始下载**。需已安装 MotrixNext（安装扩展时会自动检查，未装会提示并给出下载链接）。

- 支持 `http(s)` / `ftp` / `magnet` / `ed2k` / `thunder` 链接，以及 `www.` 开头的裸域名（自动补 `https://`）；
- 按钮只在选区里检测到链接时出现；一次选中多条会全部发送（自动去重）；
- 链接从中文句子里选出来也不怕：末尾黏着的中英文标点（`。` `，` `.`）、Markdown 标记（`**`）会被剔除，维基式 `…/Foo_(bar)` 路径保持完整，ed2k 链接里未编码的中文文件名原样保留；
- 通过 Bundle ID（`com.motrix.next`）点名调用，装了多个下载器也不会跑错应用。

## 安装

1. 在 Finder 里**双击** `.popcliptxt` 文件（`中文排版` 与 `MotrixNext下载`，想装哪个装哪个）；
2. PopClip 弹窗询问是否安装，点确认即可；
3. 之后选中文本，点 PopClip 工具条上对应的按钮：“隔”/“标”把选区替换为排版处理结果，⏬ 把选中的链接发给 MotrixNext；
4. 不想要「隔」或「标」中的某个按钮，在 PopClip 设置的扩展列表里点开「中文排版」的选项，取消对应勾选即可（默认都显示）。

> 如果之前装过旧版的「间隔标准化」「中文标点规范化」两个独立扩展，先在 PopClip 设置里移除它们，再装「中文排版」，避免工具条出现重复按钮。

## 设计取舍

这些是有意为之、可按需在源码里微调的判断：

- **单向**：只做英 → 中，不会把中文标点转回英文（如需反向，见 git 历史里的旧扩展 `中英引号互转`）。
- **冒号后跟空格**（`命令: git push`）视为西式“标签: 值”，保持半角；中文行文里的冒号（`论证了:商品`）无空格，照常转全角。
- **落单括号**（无配对的 `(` 或 `)`）保持原样，以保护 `:)`、`[0,1)` 等。
- **句号**最保守：仅当其后不是字母 / 数字 / `/` / `@` 时才转 `。`。
- **幂等**：对已规范化的文本重复运行不会再改动，可放心多次触发。
- **调用型括号**（`func(x)`、`选项A(推荐)`——左括号紧贴字母）整对保持半角、内部视为代码；数字后跟含汉字的括注（`25(虚岁)`）例外，照常转全角。

`test-example.md` 是一份带 Markdown 粗体的中文样例，用于验证转换效果。`run-tests.js` 是「中文排版」的回归测试（106 例：隔 84 + 标 22，含幂等性检查），在仓库根目录用 macOS 自带的 JXA 运行，无需安装 Node：

```
osascript -l JavaScript run-tests.js
```
