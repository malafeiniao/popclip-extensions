三个 [PopClip](https://www.popclip.app/) 插件：中文排版整理、日期标注，以及使用 [MotrixNext](https://motrix-next.pages.dev/) 下载。

| 插件 | 按钮 | 做什么 |
|---|---|---|
| **[中文排版](extensions/中文排版.popcliptxt)** | 隔 | 中文标点规范化，处理汉字与英文、数字之间的间隔 |
| **[中文排版](extensions/中文排版.popcliptxt)** | 标 | 中文标点规范化，不处理间隔 |
| **[时间标注](extensions/时间标注.popcliptxt)** | 📅 | 模糊时间补日期，明确日期补星期 |
| **[MotrixNext 下载](extensions/MotrixNext下载.popcliptxt)** | ⏬ | 把下载链接发给 MotrixNext，弹出「新建任务」面板确认 |

「隔」「标」是「中文排版」插件里的两个按钮，可在 PopClip 设置里分别开关（默认都打开），共用同一套标点转换引擎，不会破坏数字、网址、代码、时间、路径等内容。

## 一、中文排版

中文排版处理间隔的规则：

- **行首缩进**（含全角空格缩进）、**行尾空格**（Markdown 硬换行）、**制表符**（TSV）、单个**不换行空格**（nbsp）原样保留；
- Markdown **列表标记**（`- ` `1. ` `> `）后的对齐空白、**表格** `|` 两侧的空格保留；
- 汉字之间的空格一律删除，含 `第一章 绪论` 这类标题空格，如需保留请只选正文；
- 英文行文里的单词间隔保留，连续空格仍会收拢为一个空格（`word  word` → `word word`）；
- `—` `…` `·` 中英通用，只有两端都贴着中文才删空格（`Vue — 渐进式框架` 原样保留）；
- 全角标点旁（`，` `：` 等自带留白）不加空格；空格永远补在 `**` `` ` `` 等 Markdown 标记的**外侧**，不破坏加粗/行内代码；词内下划线（`订单_id`）不拆。

符号转换规则如下表：

| 类别 | 半角 / 繁体 | → 全角（简体） | 说明 |
|---|---|---|---|
| 引号 | `"` `'` | `“ ”` `‘ ’` | 仅中文语境，自动成对；保护英文撇号 `don't` 与英寸 `6"` |
| 角引号 | `「」` `『』` | `“ ”` `‘ ’` | 繁体引号 → 简体引号 |
| 逗号 | `,` | `，` | |
| 分号 | `;` | `；` | |
| 冒号 | `:` | `：` | 后跟空格的“标签: 值”保持半角 |
| 问号 / 叹号 | `?` `!` | `？` `！` | |
| 句号 | `.` | `。` | 仅句末；小数 / 缩写 / 域名不动 |
| 括号 | `( )` | `（ ）` | 成对转换；函数调用与 Markdown 链接保持半角 |
| 省略号 | `...` | `……` | 仅贴着汉字时 |
| 破折号 | `--` | `——` | 恰两个连字符且贴汉字，`--help`、`---` 分隔线不动 |
| 日式半角 | `｡ ､ ｢ ｣ ･` | `。 、 “ ” ·` | 直接映射 |

下表中的输入都不会进行转换：

| 输入 | 原因 |
|---|---|
| `1,000,000` / `3.14` / `v2.0.1` | 数字、版本号 |
| `12:30` / `2:1` | 时间、比例 |
| `http://a.com/x?y=1` / `http://例子.测试` | 网址（含未编码中文的也整体保护） |
| `user@mail.com` | 邮箱 |
| `C:/Users/me` | 路径 |
| `func(x)` / `print("你好")` / `[链接](http://x)` | 调用型括号内部视为代码 |
| `{"姓名":"张三"}` / `<div class="标题">` | JSON 花括号内部、`="…"` 属性赋值 |
| ```` ```代码块``` ```` / `` `行内代码` `` | Markdown 代码保护区 |
| `don't` / `6'5"` / `--help` | 英文撇号、英尺英寸、命令行参数 |
| `So…?` / `word — word` | 英文里的省略号、破折号不构成中文语境 |
| `哈哈 :)` | 颜文字（也不会被别的括号“偷配对”） |
| `端口: 8080` | 西式“标签: 值” |

Markdown 行内标记 `**粗体**`、`_斜体_`、`~删除~` 会原样保留。

## 二、时间标注

这个插件给模糊时间补上日期，给明确日期补上星期。

```
输入：这周四要去公园玩。      输出：这周四（08/06）要去公园玩。
输入：下周一我们可以看电影    输出：下周一（08/10）我们可以看电影
输入：截止 8月6日            输出：截止 8月6日（周四）
```

**下文例子都按“今天是 2026-08-04，周二”计算。**

选一整段也行，段落里所有时间一次全部标出，两个方向可以混在一起，已经标过的不会重标：

```
输入：需求评审排在这周四，联调下周开始，8月20日验收，月底上线。
输出：需求评审排在这周四（08/06），联调下周（08/10–08/16）开始，8月20日（周四）验收，月底（08/31）上线。
```

### 模糊时间 → 日期

| 类别 | 例子 | 标出来是 |
|---|---|---|
| 周 X | `周四` `这周四` `本周四` | 本周的周四 `08/06` |
| | `下周一` `下个星期三` `上周五` `上上周日` | 按前缀推算，`下`/`下下`/`上`/`上上` 都认 |
| | `星期天` `礼拜六` `周3` | 写法随意 |
| 周末 | `周末` `下周末` | 周六到周日 `08/08–08/09` |
| 整周 | `这周` `下周` `上个星期` | 周一到周日 `08/10–08/16` |
| 相对日 | `今天` `明天` `后天` `大后天` `昨天` `前天` `大前天` | `08/05`，也认 `今日` `明晚` `昨儿` 等写法 |
| 相对量 | `3天后` `三天后` `两周后` `两个月后` `一年前` | 中文数字、`之后`/`以后`/`之前` 都认 |
| 月 | `这个月` `下个月` `上月` | 只标到月 `09月` |
| | `月初` `月中` `月底` `下个月初` | 1 号 / 15 号 / 当月最后一天 |
| | `下个月3号` `上个月20日` | `09/03` |

**一周从周一算起**：「周四」「这周四」「本周四」是同一天，「下周一」是下一周的周一。日期紧跟在时间词后面，不会吞掉后面的时段和钟点——`明天（08/05）下午两点开会`。

### 明确日期 → 星期

| 写法 | 例子 | 标出来是 |
|---|---|---|
| 带年份 | `2026年8月6日` `2026-08-06` `2026/8/6` `2026.8.6` | `（周四）`，分隔符随便 |
| 没写年份 | `8月6日` `10月3号` | 默认今年；离今天太远会改用相邻年份，并把年份一并标出 |
| 只有数字 | `8/6` `8-6` `6号` | 认，但要**单独选中**，见下 |

没写年份的日期取“离今天最近的那一年”，8 月读到 `1月5日` 指的多半是明年，于是标成 `1月5日（2027年 周二）`。`6号` 这种只有日子的，从今天算起取下一个 6 号，跨月了就把月份标出来（`3号（9月 周四）`）。日期后面已经写了星期的（`8月6日（周四）`、`8月6日 周四`）直接跳过。

`8/6` `6号` 这类写法歧义太大（`3/4` 是分数、`3号` 可能是编号），所以只在**选区里除了它只剩标点和空白**时才转换（`8/6。` → `8/6（周四）。`）；夹在句子里的（`会议 8/6 下午`、`共 3/4 完成`）一律不动。

相关设置：

| 选项 | 默认 | 说明 |
|---|---|---|
| 日期格式 | `08/06` | 另有 `8月6日`、`2026-08-06`；结果跨年会自动补年份（`2027/01/04`） |
| 附带星期 | 关 | 开启后标成 `明天（08/05 周三）`；本身就是「周X」的说法不重复标 |
| 不带前缀的「周X」 | 算本周 | 可改成「算将来最近的那天」——周二点「周一」，得到的就是下周一 |

## 三、MotrixNext 下载

选中含链接的文本，点 ⏬ 把链接交给 [MotrixNext](https://motrix-next.pages.dev/)——它会弹出「新建任务」面板供确认，**不会静默开始下载**。需已安装 MotrixNext（安装插件时会自动检查，未装会提示并给出下载链接）。

- 支持 `http(s)` / `ftp` / `magnet` / `ed2k` / `thunder` 链接，以及 `www.` 开头的裸域名（自动补 `https://`）；
- 按钮只在选区里检测到链接时出现；一次选中多条会全部发送（自动去重）；
- 链接从中文句子里选出来也不怕：末尾黏着的中英文标点（`。` `，` `.`）、Markdown 标记（`**`）会被剔除，维基式 `…/Foo_(bar)` 路径保持完整，ed2k 链接里未编码的中文文件名原样保留；
- 通过 Bundle ID（`com.motrix.next`）点名调用，装了多个下载器也不会跑错应用。

## 四、安装

先安装并运行 PopClip，再按需选择插件：

| 插件 | 安装文件 | 额外要求 |
|---|---|---|
| 中文排版 | [中文排版.popcliptxt](extensions/中文排版.popcliptxt) | — |
| 时间标注 | [时间标注.popcliptxt](extensions/时间标注.popcliptxt) | — |
| MotrixNext 下载 | [MotrixNext下载.popcliptxt](extensions/MotrixNext下载.popcliptxt) | 已安装 MotrixNext |

1. 从 GitHub 下载 `.popcliptxt` 时，在文件页面选择 **Download raw file** 保存原文件。
2. 在 Finder 里**双击**下载的 `.popcliptxt` 文件，按 PopClip 提示确认安装，详见 [PopClip 安装说明](https://www.popclip.app/guide/extensions#installing-a-downloadable-extension)。
3. 选中文本或链接，点击对应按钮。文本处理插件会替换选区；下载插件会把链接交给对应应用。
4. 在 PopClip 中打开对应动作的设置，可以调整插件选项。「中文排版」可分别开关「隔」「标」（默认都打开）。
